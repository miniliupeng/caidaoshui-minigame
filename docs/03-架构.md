# 彩虹倒水 · 架构

TypeScript 严格模式，编译成 CommonJS 到 `js/`，目录与 `src/` 对应。微信入口只 `require('./js/main.js')`。浏览器预览另打一份 IIFE 包 `preview/game.bundle.js`，不进上传包。

## 1. 分层

依赖方向只有向内：渲染和入口可以调用对局，对局可以调用规则与服务，规则不知道微信、画布和广告。

```
game.js / index.html
        │
        ▼
src/main.ts                 启动、帧循环、对外 GameMain
        │
        ├── src/app/session.ts      唯一对局状态、点击意图、胜负、撤销、空杯
        ├── src/render/*            首页 / 对局 / 过关 / 卡住、瓶子和按钮
        ├── src/platform/*          Screen、触摸、存储、时钟
        ├── src/services/*          广告、埋点、进度、隐私
        ├── src/audio/*             音效与背景音乐
        ├── src/data/*              80 关与配色
        └── src/core/*              纯函数：规则、命中、布局、求解、晃动
```

不要在 `core/` 里读 `wx`、`game.now` 或画布。对局要倒水时调用 `core/rules`，再自己改 `game`。

## 3. 适配

`Screen` 是窗口尺寸、像素比、安全区和胶囊避让的唯一来源。

- 画布像素 = `windowWidth * pixelRatio` × `windowHeight * pixelRatio`。
- 每帧 `setTransform(dpr * ww / 750, dpr * wh / 1334)`，之后所有绘制用设计坐标。
- 真机触摸：`clientToDesign(clientX, clientY, ww, wh)`，即 `client * (设计边 / 窗口边)`。
- 浏览器预览的画布被 CSS 缩小，先换成相对画布的局部坐标，再调用同一个 `clientToDesign`。
- 静音按钮使用 `getMenuButtonBoundingClientRect` 换算后的 `menuLeft`，避免压住胶囊。

## 4. 时钟

主循环：

```
game.now = requestAnimationFrame 的时间戳
tick(dt)     推进倒水、抖动、晃动清理、粒子
render(ctx)  只读 game.now 画当前帧
```

倒水、按钮按压、转场、入场、晃动、粒子的起点都写成 `game.now`。不要在绘制函数里另取 `Date.now()` 或 `performance.now()`。`platform/clock.ts` 的 `perfNow` 只在没有 rAF 时间戳时给主循环兜底。

晃动公式在 `sampleWobble`。`dt` 不在 `[0, 380)` 时返回相位 0。会话层把这个相位写回 `game.surfacePhase`。

## 5. 对局数据

`session.game` 是唯一可变对局。字段与 MVP 对齐：瓶子、选中下标、历史、步数、免费撤销、广告空杯计数、倒水动画、抖动、粒子、提示、转场。

倒水动画期间，画面用 `applyPourLayers` 从起点液面插值，逻辑瓶子要等 `finishPour` 才改。因此中途退出动画不会出现「画面倒了、数据没倒」的半截状态；要么动画跑完，要么重开整关。

撤销栈在 `startPour`、同步倒水、以及广告空杯成功时压入。免费撤销不经过广告。

## 6. 输入

`onTap` 的优先级：

1. 抬起：只清按钮按压。
2. 转场前 85%：丢弃。
3. 对局、没在倒水、且点击在底栏以上：先处理瓶子。处理成功就返回，底栏按钮拿不到这次点击。
4. 否则命中按钮。
5. 仍是对局且没在倒水：再尝试瓶子（点击落在底栏带里时）。

空瓶、改选、取消、倒水都在 `handleBottleTap`。

## 7. 广告、存档、埋点

`showRewarded` 先记 `ad_request`，微信环境再尝试隐私授权，然后播广告，最后记 `ad_result`。会话只在 resolve `true` 时改瓶子或历史。

进度和隐私走 `platform/storage`。背景音乐沿用 MVP 的读写（同一个键 `caidaoshui_bgm_muted`），避免把旧静音偏好读丢。

`track` 不抛出到玩法。上报失败只 `console.warn`。

## 8. 构建产物

| 命令 | 产物 | 谁用 |
| --- | --- | --- |
| `tsc` | `js/**/*.js` | 微信开发者工具、`npm test` |
| `esbuild` | `preview/game.bundle.js` | `index.html` |

`js/` 和 `preview/` 不入库。改玩法只改 `src/`，然后重新构建。不要手改 `js/`。

## 9. 对外测试面

`GameMain._test` 暴露构建关卡、倒水、命中、点击、晃动和 `touchToLogic`，供点击回归使用。新规则优先直接测试 `js/core/*`，不要为了断言去画一帧。
