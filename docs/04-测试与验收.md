# 测试与验收

## 1. 本地命令

在项目根目录：

```bash
npm install
npm test
```

`npm test` 会先 `tsc` 再打预览包，然后用 Node 自带测试运行器执行 `tests/*.test.js`。不需要微信开发者工具也能看到规则、关卡和点击回归是否通过。全部关卡求解大约需要几十秒。

只想看类型：

```bash
npm run typecheck
```

浏览器里看画面：

```bash
npm run build
npm run preview
```

打开终端打印的地址（默认 `http://127.0.0.1:41773`）。预览里的「+空杯 / 撤销」会弹出确认框，确定视为看完广告。

## 2. 测试分册

| 文件 | 覆盖 |
| --- | --- |
| `tests/rules.test.js` | 完成条件、倒水合法性、倒入层数、动画逐层插值、无路可走 |
| `tests/levels.test.js` | 80 关的颜色数量、容量、空瓶、开局有步可走，以及 BFS 可解；第 1 关按求出的步数回放必须过关 |
| `tests/screen-clock.test.js` | `client * (设计边 / 窗口边)`；晃动在时窗内有值，超时和时钟回绕清零 |
| `tests/tap-clock.test.js` | MVP 的点击回归：点空瓶不删瓶、选中后倒进空瓶、左缘热区、空瓶不触发重开、重开后空瓶还在、点空白不取消选中、会话时钟、无缩放触摸 1:1 |
| `tests/session.test.js` | 免费撤销、mock 广告发空杯、空杯上限、进度只增不减、隐私同意只记一次 |

点击回归通过编译后的 `GameMain` 驱动，用来防止分层之后把「瓶子优先于底栏」做丢。

关卡数据若改了 `src/data/levels.ts`，必须让 `tests/levels.test.js` 继续通过。求解器认为已经同色倒满的瓶子不必再倒出；每种颜色恰好 4 层时，这不会把有解的关卡判成无解。

## 3. 微信开发者工具

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)，基础库与 `project.config.json` 的 `libVersion`（当前 3.5.5）同级或更高。
2. 在项目根目录执行 `npm install` 和 `npm run build`，确认生成了 `js/main.js`。
3. 开发者工具选择「小游戏」，导入**本仓库根目录**（能看见 `game.js`、`game.json`、`project.config.json` 的那一层），不要只导入 `src/`。
4. AppID 使用 `wx50da0aafbce43359`。没有该小游戏权限时，用测试号也可以看玩法，但激励视频会创建失败，此时不应发奖。
5. 详情里确认编译类型是小游戏、竖屏。模拟器选常见手机竖屏，再切一次异形屏，看静音按钮是否让开胶囊。
6. 控制台应出现 `[彩虹倒水] ready 0.3.0`，以及 `[track] app_launch`。
7. 真机预览前，把 `src/services/placements.ts` 里的占位广告位换成流量主后台的真实 ID，重新 `npm run build`。

上传忽略列表已经排除源码、文档、测试和 `node_modules`。上传包里应有 `game.js`、`js/`、`audio/`、`images/`、`avatar_caise.png`。

## 4. 验收清单

玩法：

- [ ] 首页能开始第 1 关；通关后退出再进，出现「继续」且进入下一关。
- [ ] 第 1 关点空瓶，瓶子数量不变，出现抖动和提示，不会重开。
- [ ] 点有水的瓶子再点绿色空瓶或同色瓶，能看到倾倒，步数 +1。
- [ ] 异色、满瓶不能倒入，并有文案。
- [ ] 点空白不取消选中；再点已选中的瓶子可以取消。
- [ ] 免费撤销 3 次有效；第 4 次走广告。广告中途关闭，局面不变。
- [ ] 广告空杯最多 2 个。加上之后如果还有路，从卡住页回到对局。
- [ ] 过关有粒子和步数，下一关关卡名正确。最后一关是「再玩一轮」。
- [ ] 重开本关回到初始液面，免费撤销和空杯计数恢复。

表现与适配：

- [ ] 竖屏，瓶子在顶栏和底栏之间，不与胶囊重叠。
- [ ] 倒水后液面只短晃一下，停住后不再闪。
- [ ] 首页主视觉能显示；断图时仍能看到示意瓶和按钮。
- [ ] 静音切换后重进小游戏，仍然保持。
- [ ] 切到后台再回来，未静音时背景音乐可恢复。

合规与商业：

- [ ] 首次主按钮是「同意并开始」或「同意并继续」，页脚能看到本机存档和激励广告说明。
- [ ] 公众平台已配置用户隐私保护指引。
- [ ] 真实广告位已替换占位符。看完才发奖，失败或中途退出不发奖。
- [ ] 控制台能看到 `level_start`、`pour_commit`、`level_clear` 或 `ad_result`。后台未配置事件时，游戏仍可玩。

工程：

- [ ] 根目录 `npm install && npm test` 通过。
- [ ] 没有手改 `js/`。改动都在 `src/` 或文档、测试里。
