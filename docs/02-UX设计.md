# 彩虹倒水 · UX

设计分辨率 750×1334，竖屏。真机上由 `Screen` 映射到窗口，并让开状态栏、安全区和右上角胶囊。浏览器预览把画布 CSS 盒子当成同一套换算的窗口。

## 1. 信息架构

```
首页 home
  ├─ 开始 / 继续 → 对局 play
  ├─ 玩法说明 → 首页上的短提示
  └─ 静音

对局 play
  ├─ 倒水成功且全完成 → 过关 clear
  ├─ 倒水成功但无路 → 卡住 stuck
  ├─ 撤销 / 空杯 / 重开 → 仍在 play（卡住页里的撤销和空杯会回到 play）
  └─ 静音

过关 clear
  ├─ 下一关或再玩一轮 → play
  └─ 回首页 → home

卡住 stuck
  ├─ 广告空杯或撤销成功 → play
  ├─ 重开本关 → play
  └─ 回首页 → home
```

## 2. 状态机

```
                 同意并开始 / 继续 / 重开
        home  ------------------------------→  play
          ↑                                    │  │
          │ 回首页                              │  │ 无合法步
          │                                    │  ↓
        clear  ←—— 全部瓶子完成 —— play ——→  stuck
          │                         ↑            │
          └── 下一关 / 再玩一轮 ─────┘            │
                         ↑    广告空杯或撤销成功 ─┘
                         └──── 重开本关 ─────────┘
```

`play` 在倒水动画未结束前不接收瓶子点击。转场动画前 85% 的时间里忽略点击，避免连点跳关。

## 3. 首页

自上而下：

1. 静音按钮在胶囊左侧，文案「音 / 静」。
2. 标题「彩虹倒水」，副标题「把同色水倒进同一个瓶子」。
3. 有进度时显示已解锁关卡；否则提示可以用广告加空杯或撤销。
4. 主视觉优先画 `images/home-hero.png`，失败再用包根的 `avatar_caise.png`，再失败就画三只示意瓶。
5. 主按钮。没有进度时是「开始闯关」；已同意且有进度时是「继续闯关 · 第 N 关」，下面还有「从第 1 关开始」。尚未同意时主按钮改成「同意并开始」或「同意并继续」。
6. 「玩法说明」用底部提示写出规则，不新开页面。
7. 页脚一行：本机存档、微信激励广告、总关数。

入场用 700ms 的回弹位移。若首帧时钟比入场时间戳更早，把起点改成当前 `game.now`，避免真机上标题一直透明。

## 4. 对局

顶栏左侧是关卡名，下一行从左排开步数、免费撤销和空杯计数，避免和右上角静音按钮叠在一起。中间一行操作提示：

- 未选中：「点选一个有水的瓶子」
- 已选中且有目标：「已选中 · 再点高亮瓶倒水（N 个可倒）」
- 已选中但没有目标：「已选中 · 暂无可倒目标，点同一瓶取消」

第 1 关、还没走步、引导未关时，顶栏下有两行引导。

瓶子：

- 选中：上移，粉色描边。
- 可倒入：轻微上移，绿色描边，空瓶写「空」。
- 倒水：来源瓶倾斜，中间有同色水柱，目标瓶轻微晃。
- 非法：短抖动，并给出「已满 / 改选 / 不能倒入」之一。
- 同色倒满：瓶心打勾。

底栏三个等宽按钮，热区下沿就是瓶子点击的下边界，空瓶点不中「重开」：

| 按钮 | 行为 |
| --- | --- |
| 撤销 · N / 广告撤销 | 有免费次数就直接撤销，否则看广告 |
| + 空杯 | 看广告，本关最多 2 次 |
| 重开 | 重开本关，免费次数和广告空杯计数重置 |

提示条出现在底栏上方，不挡瓶子中心。

## 5. 过关与卡住

两者都在对局画面上盖一层遮罩和白卡片，保留背后的瓶子，让玩家认出刚才的局面。

过关卡片有粒子和步数。「下一关」或最后一关的「再玩一轮」，以及「回首页」。

卡住卡片说明「看广告加空杯，或撤销一步」，按钮顺序是：广告空杯、撤销、重开、回首页。空杯达到上限时，广告成功回调里会提示上限，局面不变。

## 6. 交互细则

- 点选反馈要在手指抬起前就发生（`touchstart` / `pointerdown`），抬起只取消按钮按压态。
- 按钮按下缩到 0.94，约 160ms。
- 音效：点选、倒水、非法、胜利、按钮。背景音乐循环，音量 0.45，可静音并记住。
- 第一次触摸同时解锁音频和背景音乐，满足微信对用户手势的要求。
- 文案用完整句子，不用占位符。错误都告诉玩家下一步该点哪里。

## 7. 视觉与动效

情绪是浅色、偏粉紫的休闲，不是暗黑或写实液体模拟。

- 背景是竖向渐变加很慢移动的色块，色块不闪。
- 液体用上亮下暗的三段渐变，顶层有一条短命的高光。晃动只在倒水后 380ms 内出现。
- 可倒目标的绿色圈是静态的，不用高频呼吸灯。
- 过关粒子是一次性的，生命周期到了就移除。
- 进关转场是一块淡入淡出的浅色遮罩，中间闪关卡名。时长 480ms。
- 所有动画时间戳只写 `game.now`。`game.now` 由主循环的 `requestAnimationFrame` 时间戳驱动，和首帧入场共用一个时钟。

## 8. 首次引导

1. 打开即首页，不自动进关。
2. 主按钮同时完成隐私同意和开局，避免先弹一个无法操作的协议层再点一次开始。
3. 第 1 关顶上两行字，点过瓶子后消失。
4. 「玩法说明」在首页随时能再看。
5. 不强制教学关动画手，规则用第 1、2 关的低颜色数承担。
